# 🌐 Website Biografi Dimas Artha

[![GitHub Pages](https://img.shields.io/badge/GitHub%20Pages-Live%20Demo-brightgreen?style=for-the-badge&amp;logo=github)](https://dimasartha.github.io/Biografi-Dimas-Artha/)
[![Website Status](https://img.shields.io/website?url=https%3A%2F%2Fdimasartha.github.io%2FBiografi-Dimas-Artha%2F&amp;style=for-the-badge&amp;logo=github)](https://dimasartha.github.io/Biografi-Dimas-Artha/)

Website personal yang menyajikan biografi, profil, dan informasi lengkap mengenai Dimas Artha. Proyek ini dibuat sebagai web portofolio yang bersih, interaktif, dan responsif.

---

## 🚀 Fitur Utama

* **Informasi Biografi Lengkap:** Menampilkan profil pribadi dan perjalanan Dimas Artha.
* **Desain Responsif:** Tampilan yang nyaman diakses melalui berbagai perangkat (Desktop, Tablet, maupun Smartphone).
* **Struktur Rapi:** Menggunakan pemisahan kode HTML, CSS, dan JavaScript secara terorganisir.
* **Galeri &amp; Media:** Dilengkapi folder aset gambar untuk mendukung visualisasi informasi.

---

## 🛠️ Teknologi yang Digunakan

Proyek ini dibangun menggunakan stack teknologi web dasar:

* **HTML5** (`index.html`) – Struktur utama halaman web.
* **CSS3** (`style.css`) – Penataan gaya, warna, dan tata letak responsif.
* **JavaScript** (`scripts/`) – Skrip interaktivitas halaman web.
* **Media Assets** (`img/`) – Penyimpanan berkas gambar pendukung.

---

## 📂 Struktur Direktori

```
Biografi-Dimas-Artha/
├── img/          # Folder penampung aset gambar
├── scripts/      # Folder skrip JavaScript
├── index.html    # Berkas utama (entry point) website
├── style.css     # Berkas gaya CSS
└── README.md     # Dokumentasi resmi proyek

```

---

## 💻 Cara Menjalankan secara Lokal

1. **Clone Repositori:**  
```  
git clone https://github.com/Dimasartha/Biografi-Dimas-Artha.git  
```
2. **Masuk ke Direktori Proyek:**  
```  
cd Biografi-Dimas-Artha  
```
3. **Buka di Browser:** Klik dua kali pada berkas `index.html` atau buka menggunakan ekstensi *Live Server* di editor kode pilihan Anda (seperti VS Code).
